# Overkill — песочница разрушения для Minecraft (Fabric)

Мод про масштабное разрушение. В руках у игрока **пульт**: наводишься на точку,
выбираешь удар в 3D-меню — и по цели прилетает что-то очень большое, с кино и
взрывами. Всё на движке **Fabric**, со своими эффектами, звуком и генерацией.

> Minecraft **26.1.2** · Fabric Loader **0.20.1** · Fabric API · Java **25**

## Возможности

- **Пульт управления.** ПКМ открывает 3D-меню навыков прямо в мире; колёсиком
  крутишь мощность и радиус, наводишься прицелом на цель.
- **Удары.** Межконтинентальные ракеты, метеориты, орбитальные спутники,
  бурильные снаряды, бомбы — с «начинкой»: ядерный кратер, заморозка, остекление,
  ад, трещины и другое.
- **Кино.** Перед ударом — кинематографичный пролог: камера уходит в космос,
  показывает пуск и подлёт, затем удар.
- **Гравитация и мир.** Управление гравитацией, деформация и перегенерация
  рельефа, блок «чанк-сплиттер».
- **FX.** Взрывы, частицы, тряска камеры и объёмный многослойный звук.

## Установка (обычный лаунчер)

1. Установите **Fabric Loader** для Minecraft **26.1.2** — [fabricmc.net/use](https://fabricmc.net/use).
2. Скачайте **Fabric API** для 26.1.2: [modrinth.com/mod/fabric-api](https://modrinth.com/mod/fabric-api).
3. Со вкладки [**Releases**](https://github.com/MagicFakeDS/overkill/releases) скачайте
   `mymod-1.0.0.jar` (без `-sources`).
4. Положите `fabric-api-….jar` и `mymod-1.0.0.jar` в папку модов:
   - Windows: `%APPDATA%\.minecraft\mods`
   - Linux: `~/.minecraft/mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
5. Запустите Minecraft с профилем **fabric-loader 26.1.2** (нужна Java 25).
   Пульт лежит в творческом режиме во вкладке «Инструменты».

## Сборка из исходников

Нужна только JDK 25 (например, Eclipse Temurin) — Gradle скачивается сам через `gradlew`.

```bash
./gradlew runClient    # запустить игру с модом (лаунчер и лицензия не нужны)
./gradlew build        # собрать .jar -> build/libs/mymod-1.0.0.jar
```

## Структура

```
src/main/java/com/example/mymod/
    MyMod.java            точка входа мода
    skill/                навыки-удары: доставка (ракета, бомба, спутник, бур) + начинка
    fx/                   взрывы, частицы, звуки
    world/                гравитация, деформация и генерация рельефа
    item/ block/ network/ пульт, блоки, сетевые пакеты
src/client/java/com/example/mymod/   клиент: 3D-меню, кино-камера, FX, миксины
src/main/resources/assets/mymod/     текстуры, модели, звуки
```
