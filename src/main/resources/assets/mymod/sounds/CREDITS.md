# Звуки оружия

Все записи — с лицензией **CC0** (общественное достояние): их можно использовать и распространять
без указания автора. Авторов всё равно перечисляем — из уважения.

| Что | Откуда | Автор |
|---|---|---|
| Выстрелы (Walther PPQ, Bersa, 1911, S&W 642, Carl Gustav M45, PPSh, AK-47, AR-15, Мосин, Springfield 1917, Tikka T3, Arisaka, Benelli Nova, Winchester Model 12) | [The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library) | Still North Media |
| Патрон в магазин, магазин вставлен (singlebullet1, clipload1/2) | [Gun Reload Sound Effects](https://opengameart.org/content/gun-reload-sound-effects) | Brian MacIntosh (BMacZero) |
| Магазин выпал, затвор пистолета (reload.wav) | [Handgun Reload Sound Effect](https://opengameart.org/content/handgun-reload-sound-effect) | zer0_sol |
| Помпа, патроны в трубку дробовика | [Shotgun Reload Sound effects](https://opengameart.org/content/shotgun-reload-sound-effects) | zer0_sol |

Остальные звуки (сухой щелчок, затвор винтовки, гильзы, рикошет, свист пули, попадания, броня)
синтезированы скриптом `tools/make_gun_sounds.py`.

Пересобрать звуки из записей: скачать архивы в `downloads/` и запустить `python tools/real_sounds.py`.
